# 自动收尾与网页进度规范

任务控制程序负责模型阶段；报告服务负责收尾；网页负责观察。三个部分分别保存状态，关闭网页不停止服务器上的收尾服务。

| 步骤 | 触发条件 | 自动执行 | 失败后的处理 |
|---|---|---|---|
| 注册 | 控制程序创建任务 | 用 case/run ID 注册私有运行目录和白名单统计 | 重试注册，不启动模型 |
| 执行 | 任务已启动 | 出图、独立重建及原有评分流程 | 保留失败记录，不自动创建新模型尝试 |
| 核对 | 冻结结果和评分出现 | 核对 DXF/PNG/STEP 清单、哈希及同模型对照 | 标记报告失败，不发布不一致结果 |
| 报告 | 核对通过 | 提取最终视图、生成对比预览、精简 JSON 与独立 HTML 报告 | 重试报告；不重建模型、不重算 IoU |
| 发布 | 结果包通过隐私与格式检查 | 先写展示文件，最后原子更新动态结果目录 | 使用同一包重试，不重跑模型 |
| 展示 | 后台目录更新 | 网页每 60 秒读取进度和结果，无需手动刷新整页 | 保留已有结果，提示状态源无法访问 |

**执行、评分、报告与发布不能共用一个“成功/失败”值。**例如评分完成后上传失败，应显示“已评分 / 发布待重试”，而不是“模型失败”。已计算的评分证据优先于过期的本地 stopped/failed 心跳。没有评分仍为 null，不能当作零分。

控制程序在任务创建时调用 `benchcad_runtime.progress.register()`，或运行 `tools/workbench_progress.py`。注册表只放在服务器私有目录，包含任务目录映射和经过白名单处理的公开统计，不放在网站上。注册 ID 对应的源目录不可悄悄替换。

自建控制程序增加 `--case-number` 与 `--progress-registry <private-registry>` 即可自动注册、写阶段心跳，并在收尾时交接最终统计。开始时 `report_ready=false`，统计与报告包完成后变为 true，防止在 CLI 最终 token 尚未交接时提前冻结报告。已成功的独立评分重试可以通过私有 `evaluation_run` 指定，原重建目录保持不变。

CLI 控制程序知道最终 token 用量后，应更新注册表的 `public_run` 统计。运行中未知用量保持 null。模型控制程序仍在本地的情况下，这是一条必要的统计交接；网页查询、评分等待和报告发布不需要经过本地电脑中继。

服务入口为工作台的 `progress_service.py --config <private-config>`。部署为服务器常驻服务，读取同机运行目录，每分钟更新公开快照。它不发起模型请求，不调用评分器，只调用固定的受限预览导出程序。

公开快照：

- `cadquery-live/status.json`：白名单进度数据，包含阶段、执行用时、评分、发布时间和更新时间。
- `cadquery-live/catalog.json`：已审核结果目录，新 case 和多次运行都通过此目录自动出现在页面。
- `cadquery-runs/case-XXX/run-id/report.html`：自动生成的独立报告。

动态快照与静态网页发布清单分开。网页换版不会把实时结果当作不可变静态文件校验；后台从缓存包恢复动态结果。静态源代码、动态结果和私有运行目录各有边界。

## 3D 显示缓存

“已有 IoU 分数”“已有静态对比 PNG”“可打开 3D 查看器”是三个不同的条件。完成评分后，报告服务还需生成并检查 `geometry.json`，再发布 `viewer.html` 和结果目录中的 `diff_viewer` 链接；不能仅凭分数或 PNG 把按钮标成可用。

显示导出只使用冻结 STEP、已保存的对齐变换和当次评分器代码快照，复现体素集合与表面网格。体素交并比必须与原 IoU 一致，否则拒绝发布；不会搜索新的对齐、修改评分或调用模型。首次导出需要 CAD 计算，生成后复用缓存。

显示缓存作为独立补充文件保存，不改已冻结的结果包。导出失败只重试显示缓存，并保留已经完成的报告与成绩；退避重试避免持续占用资源。网页换版后补发缓存，完成导出时重新解析当前网页版本，避免写入旧版本。验收应遍历所有已评分运行，检查链接、颜色切换、旋转、单模型模式和缓存 IoU 一致性。

后台状态只说明报告服务在线。网页另外显示任务结果的更新时间，不能用“网页能访问”推断模型仍在工作。检查、心跳和网页刷新不产生模型 token。

原始会话、CLI/API 日志、账户认证、个人路径、服务器连接信息、私有 GT 和源 STEP 都不进入公开快照。报告只引用审核后的图片、视图 JSON、指标与显示缓存。公网页面没有执行任意命令、读取私有目录或启动模型的接口。
