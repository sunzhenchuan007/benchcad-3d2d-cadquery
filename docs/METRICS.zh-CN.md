# 三项 Metric：设计、评分和边界

当前评分规则：`drawing-product/3`。三个分数都在 0～1 之间，最终分数 = 重建一致性 × 专家偏好 × 文字碰撞。

三项分别回答：图纸能否准确表达形状、是否符合专家的视图与剖切要求、文字是否清楚可读。任何一项缺少必要证据，总分保持空值，不把“未评分”当作 0 分或满分。

## 1. 重建一致性：图纸表达的形状是否准确

**输入：** 原始 STEP，以及另一个独立 AI 根据出图结果重建的 STEP。重建 AI 不接触原始 STEP、专家答案或出图 AI 的对话记忆。

**方法：** 两个模型各自居中，并按各自最长包围盒边等比例归一化。在 128 格每轴的体素网格上，比较 24 个轴向旋转和 24 个镜像方向，取最高 IoU。这不是任意角度配准；绝对尺寸与左右手性不由这个指标约束。

**先去掉基准体贡献：**

```text
b = 原始模型与基准盒体、球体、圆柱体的 IoU 中最大值
q = clamp((原始 IoU − b) / (1 − b), 0, 1)
```

这里是扣除简单基准体带来的重合，不是从模型中删除外壳。若 b = 1，则原始 IoU = 1 时 q = 1，否则 q = 0。专家 DXF → AI 重建 STEP 的修正仍然暂停。

**再映射为分数 R：**

| 校正后的 q | R |
|---|---|
| q ≤ 0.90 | 0 |
| 0.90 < q < 0.995 | (q − 0.90) / 0.095 |
| q ≥ 0.995 | 1 |

例如 q = 0.9475，R = 0.5。原始 IoU、基准值 b、校正值 q、选中方向和最终 R 都保存，不用新解释覆盖历史原始成绩。

## 2. 专家偏好：视图数量与必要剖切是否合适

**输入：** 专家标注 JSON，以及评测程序从操作记录和最终图纸核验后生成的 JSON。AI 不需要自己填写评分 JSON。

**证据链：** 工具记录视图创建、删除和导出 → 控制程序冻结日志与图纸 → 评测器根据原始 STEP 重新生成对应视图并核对最终 DXF → 生成可比较的 `sections.json`。仅有日志或 AI 的自述不等于已核验。

**视图数量扣分：** 令专家参考方案的主要视图加局部视图总数为 G，AI 的总数为 A。当主要视图数量相同时，允许 AI 多一个局部视图；其余情况无额外额度。

```text
数量扣分 = max(0, A − G − 额外额度) / G
```

数量相同或更少不扣分，也不额外加分。专家有多个完整参考方案时，选数量扣分最少的一个，不能拼接不同方案的局部规则。G = 0 属于配置不足，不能直接给满分。

**必要剖切扣分：** 每缺少一个必需剖切要求扣 0.2。可选要求不扣分；同一个“任选其一”组只算一个要求。比较剖切平面是否经过规定轴线、包含规定线段、在指定位置穿轴及满足方向容差，不比较 A-A/B-B 名称是否一致。

```text
专家偏好 E = max(0, 1 − 数量扣分 − 0.2 × 缺失要求数)
```

主要视图包括普通投影、全剖与半剖；局部视图包括局部剖和局部放大。公式支持这些分类，但当前 CQ 几何证据核验仅覆盖工具生成的整体投影与全剖。任意自绘局部图、半剖的核验，以及 SW 原生剖切证据适配仍未完成。缺少核验能力时保持未评分，不假装已完成全部 JSON 比较。

## 3. 文字碰撞：文字是否被遮挡或挤在一起

**输入：** 最终 DXF 中的可见文字与几何对象。规则版本为 `rendered-ink-contact/1`。

**重叠、穿过、边缘接触都算碰撞。** 字很小时，刚好贴在一起也会影响阅读。存在明确间隙则不扣分；当前不额外设置“距离太近”的扣分项。

| 情况 | 是否扣分 |
|---|---|
| 文字与文字接触或重叠 | 是 |
| 文字与视图轮廓接触 | 是 |
| 文字与尺寸线、尺寸界线、引线或箭头接触 | 是 |
| 文字与中心线、剖切线接触 | 是 |
| 标注线与视图轮廓相交 | 否 |
| 其他线与线相交 | 否 |
| 错层本身 | 不单独扣分 |

标题栏、表格中的文字也检查。同一个尺寸标注内部的文字与线条也检查，不能整体豁免。图层仅辅助归属，不用图层名称跳过可见文字或可见线条。

**检测步骤：**

1. 展开图块、原生尺寸标注和支持的多重引线；读取文字内容、位置和对象编号。
2. 用 ezdxf 渲染前端取得字形轮廓，保留 O、8 等字形内部空白；按实际虚线间隙和解析后的线宽生成线条覆盖区域。
3. 用空间索引筛选相近对象，再检查实际覆盖区域是否相交或接触。文字外接框只用于标红展示，不作为扣分依据。
4. 对碰撞去重、计算扣分，并另外保存检查图纸。

字形曲线与圆弧按 0.001 mm 精度离散；接触计算的数值容差为 1e-8 mm，不是额外安全间距。线段端部及转角按圆形近似。不同字体、CAD 查看器和打印设置仍可能有差异，不能宣称完全等同于纸面效果。

**去重与分数：** 同一文字对算一次；同一段文字与同一视图的多条轮廓线接触算一次；同一段文字与同一原生标注的多条线接触算一次。同一个几何实体只分入一组，不在不同类别重复扣分。

```text
文字碰撞 C = max(0, 1 − 0.05 × 去重后的碰撞数)
```

如果标注已经拆成无归属的独立线段，目前按独立对象计数，不能仅凭位置相近就断言属于同一标注。这是当前去重能力的限制。

**输出：** 每处碰撞保存文字内容、对象编号、图层、碰撞类别和坐标。另存 `drawing-collision-check.dxf` 与 PNG：底图黑色，受影响文字的外框标红。红框表示此文字有接触，不表示框内所有线条都有问题。原始提交和历史报告不覆盖。

**覆盖不足如何处理：** 缺失指定字体时，保存替代字体下的诊断位置，但碰撞分数为空；这是评测环境问题，不扣 AI 的分。记录请求字体、实际解析字体及可取得的字体文件哈希。可用的标准 SHX 字体映射可以采用，任意默认替换不能悄悄视为原字体。MTEXT 内嵌字体覆盖及跨平台字体差异仍需校准。当前不检查剖面填充线、栅格文字或已转轮廓的文字语义；不支持的实体与非空图纸空间会明确标为未评分。

检查版不能重新当作原始提交评分；输入含检查覆盖层时会标记为未评分，也不会用这个层名跳过文字。关闭、冻结或隐藏的对象不属于当前可见碰撞范围。是否缺少应有内容，由其他指标与后续完整性检查负责。

## 4. 总分与记录

例如 R = 0.8、E = 0.9、C = 0.95，最终得分为 0.684。若 E 尚未评分，则总分为空，即使 R 已经为 0 也不冒充完整评分。

每次保存规则版本、三个分项、扣分明细、输入文件哈希和检查耗时。碰撞检查在评测阶段运行，不消耗 AI 交互轮次；不自动向 AI 发出错层修正要求。AI judge 留待后续验证，目前不参与评分。
